# Description --
    * Imported the Olist Brazilian E-commerce dataset from Kaggle into MySQL and performed SQL-based data analysis to extract meaningful business insights.

# Entities --
    * olist_customers_dataset
    * olist_geolocation_dataset
    * olist_order_items_dataset
    * olist_order_payments_dataset
    * olist_order_reviews_dataset
    * olist_orders_dataset
    * olist_products_dataset
    * olist_sellers_dataset
    * product_category_name_translation

# Key Analyses --

    * Analyzed total orders and order status distribution.
    * Identified top customers based on order frequency.
    * Evaluated delivery performance, including average delivery time and late deliveries.
    * Analyzed order distribution across states and cities.
    * Calculated yearly sales revenue, including freight charges.
    * Identified top-selling product categories by item count and revenue.
    * Analyzed customer payment methods.

# SQL Concepts Used -- 

    * SELECT, WHERE, GROUP BY, ORDER BY.
    * Aggregate functions (COUNT, SUM, AVG).
    * JOINs and subqueries
    * Common Table Expressions (CTEs).
    * Window functions (DENSE_RANK, SUM OVER).
    * Date and time functions.
    * CASE statements.

# Tools Used --
    * Mysql Workbench.
    * Mysql.
